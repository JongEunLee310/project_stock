# Quality Process Policy

절차 준수와 CI 통과만으로는 Blocking 결함을 걸러내지 못한다. 이 문서는 설계 판단과
검증의 사각지대에서 결함이 새어 나오는 것을 막기 위한 개발 프로세스 품질 규율을 정의한다.
아래 규율은 우선순위 순으로 나열하며, 앞선 규율일수록 결함 발생의 상류(上流)에 놓인다.

## Rationale

`docs/experiments/orchestrator-comparison-round4.md`에 기록된 오케스트레이션 실험
라운드3·4에서 도출한 규율이다. 두 라운드 모두 절차를 지키고 CI를 통과했음에도 Blocking
결함이 남았다. 병목은 절차 자체가 아니라 설계 판단과 검증의 사각지대였다.

특히 라운드4의 치명 결함은 설계 문서에 적힌 미검증 리터럴(소문자 severity 가정)에서
비롯됐다. 이 가정이 핸드오프와 구현, 그리고 테스트까지 그대로 전파됐고, 같은 가정으로
합성한 테스트 픽스처가 그 값을 다시 확인해 주면서 결함이 스스로를 정당화하는 자기 일관
구조가 만들어졌다. 결함이 있는데도 모든 단계가 초록불이었던 이유가 여기에 있다.

## Design Fact Grounding

설계 문서에 등장하는 모든 데이터 계약 리터럴에는 출처를 명시한다. 대상은 enum 값, 필드
형식, 경계값, 키 스킴 등 생산자 코드와 맞아야만 성립하는 값이다. 출처는 `파일:행` 형태의
위치나 실제로 실행한 확인 명령으로 적는다.

출처를 제시할 수 없는 값은 "가정(assumption)"으로 명시적으로 표기한다. 가정으로 표기된
값이 있으면 핸드오프는 구현에 앞서 그 값을 실제 생산자 코드에 대해 검증하도록 요구한다
(`handoff-policy.md`).

## Real-Contract Fixtures

테스트 픽스처에 들어가는 계약 값은 실제 생산자 코드에서 복사하고 출처를 주석으로 남긴다.
그렇게 하기 어렵다면, 최소 한 개의 테스트는 생산자 경로를 실제로 관통하도록 작성해 계약
값이 합성이 아니라 실측에 근거하게 한다.

관리 대상은 커버리지 수치가 아니라 "이 테스트가 무엇에 대해 참인가"이다. 생산자가 만드는
값과 무관하게 합성된 픽스처는 통과해도 계약을 보증하지 못하며, 라운드4처럼 잘못된 가정을
재확인해 주는 함정이 된다.

## Vertical Slice First

어떤 구성에서도 실제로 실행되지 않는 휴면 골격보다, 좁더라도 끝까지 배선되어 실제로
발화하는 경로를 우선한다.

도달 불가능한 코드는 오직 테스트로만 검증되며, 그 테스트는 다시 Real-Contract Fixtures가
지적한 함정에 빠지기 쉽다. 실행 경로가 실제로 한 번이라도 관통하면 계약 불일치가 런타임에
드러날 여지가 생기지만, 휴면 코드에는 그 여지조차 없다.

## Two-Pass Design

설계 초안 작성자와 검토자를 분리한다. 가능하면 모델이나 주체를 서로 다르게 둔다.

단일 주체가 설계와 검토를 모두 맡아야 하는 경우에는 "모든 리터럴 계약의 출처를 대라"는
관점의 셀프 검토 체크포인트를 명시적으로 수행한다. 초안 작성 흐름과 분리된 별도의
단계로 두어, 작성 당시의 가정을 스스로 다시 심문하게 한다.

## Cross-Model Review

구현자의 자기 검증과 CI와는 별개로, 구현에 관여하지 않은 다른 모델의 독립 리뷰를 로컬
리뷰(`local-review-policy.md`)에 추가한다.

서로 다른 모델이 같은 결함을 독립적으로 적발하면 그 결함에 대한 확신도가 올라간다.
반대로 한 모델만 통과시킨 결함은 그 모델의 사각지대일 수 있으므로, 독립 시점을 하나 더
확보하는 것이 목적이다.

## Acceptance Criteria First

핸드오프에 앞서 이슈의 요구 불릿을 수용 기준(acceptance criteria)으로 번역한다. 가능하면
검증 명령 수준까지 구체화한다. 이 저장소에서는 다음 명령이 기준점이 된다.

- `uv run ruff check .`
- `uv run mypy .`
- `uv run pytest`
- `uv run alembic heads`

요구를 수용 기준으로 먼저 번역해 두면 범위 해석 차이를 줄이고, "완결" 여부를 판정 불가능한
상태로 남겨 두지 않는다.
