# PR #422 로컬 리뷰 — theses 도메인 구조 통일 — conflict_* prefix를 conflicts/ 서브디렉터리로 이동 (#419)

## Review Summary

`theses` 도메인의 thesis conflict 하위 구성요소를 `signals/rules/`와 동일한 서브디렉터리 방식으로 정렬하는 순수 구조 이동 PR입니다. 커밋은 한 건이며 구현과 핸드오프 문서(`.codex/tasks/task-419-theses-structure.md`)가 함께 들어 있습니다.

`conflict_{model,repository,schema,service}.py` 4개 파일을 `git mv`로 `app/domains/theses/conflicts/`로 옮기고 `conflict_` prefix를 제거했으며, `conflicts/__init__.py`를 추가했습니다. import 경로 갱신은 세 갈래입니다. 첫째, 이동한 파일 사이의 내부 상호 참조(`conflicts/service.py`가 `conflicts/repository.py`·`conflicts/schema.py`를, `conflicts/repository.py`가 `conflicts/model.py`·`conflicts/schema.py`를 import). 둘째, 외부 app 참조 4곳(`analysis/service.py`, `signals/rules/base.py`, `adapters/llm/prompts/thesis_conflict.py`)과 `app/db/models.py`의 모델 등록 side-effect import 1곳. 셋째, 테스트 3파일(`test_rule_engine.py`, `test_thesis_conflict.py`, `test_llm_factory.py`). 클래스명 등 심볼과 로직·테스트 기대값은 그대로이며 바뀐 것은 모듈 경로뿐입니다.

이번 리뷰는 이동 누락(잔여 참조·등록 import)과 로직 무변경 여부를 축으로 봤습니다.

Out of Scope로 지정한 비-conflict 파일(`theses/model.py` 등)과 로직·시그니처는 변경되지 않았고, 파일 이동이 `git mv`로 이력을 보존한 rename으로 기록됨을 `git status`에서 확인했습니다. Protected Files는 없습니다. 별도 테스트 추가는 없으나, 순수 이동이므로 기존 테스트(thesis conflict·rule engine·llm factory)가 새 경로에서 통과하는 것으로 회귀 부재가 검증됩니다. Blocking·Suggestions는 없고 Questions Q1은 리뷰 중 해소됐습니다.
