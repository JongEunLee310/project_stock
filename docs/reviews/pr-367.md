# PR #367 로컬 리뷰 — 유사 과거 판단 검색 API (#365)

## Review Summary

판단 기록 재설계 3차입니다. 기준 판단과 유사한 과거 판단을 정량 유사도로 찾는 `GET /api/v1/decision-logs/{id}/similar`를 추가합니다. 신규 마이그레이션은 없습니다.

`DecisionLogRepository.list_similar(base, user_id, limit)`가 사용자 소유 판단을 불러와 유사도를 점수화합니다: 같은 대상(강), 같은 `decision_type`(중), 겹치는 `risk_type` 수(가점). 기준 판단 자신과 `superseded_by_id` 버전 체인은 `_version_chain_ids`로 제외하고, 위험 태그는 `list_risk_types_by_decision` 배치 로딩으로 얻습니다. `DecisionLogService.list_similar`는 소유 확인(404/403) 후 후보를 `_to_list_items`로 경량 항목에 매핑하고, 라우트는 `limit`(기본 5, 1~20)를 받습니다.

이번 리뷰는 유사도 규칙·버전 체인 제외·소유권·경량 응답 재사용을 축으로 봤습니다.

## Blocking

None.

## Suggestions

**S1. 사용자 판단 전량 로드 후 파이썬 점수화 — 현재 규모에서 허용.** `list_similar`는 사용자의 모든 판단을 메모리에 올려 점수화합니다. 사용자당 판단 수가 소규모라 부담이 없고, 유사도 규칙이 태그 겹침 등 집합 연산이라 파이썬이 명확합니다. 데이터가 크게 늘면 후보를 대상·유형으로 1차 필터링해 로드량을 줄이는 최적화를 후속으로 두면 됩니다.

## Questions

**Q1. 기준 판단 자신과 버전 체인이 확실히 제외되는가.** `_version_chain_ids(base.id, ...)`로 기준 판단과 `superseded_by_id`로 연결된 판단을 후보에서 제거함을 확인했고, 테스트가 자신·버전 체인 제외를 덮어 해소됐습니다.
