# PR #457 로컬 리뷰 — feat: 클라우드 LLM 자유 텍스트 민감정보 마스킹(Q&A·Decision Assist) (#456)

## Review Summary

클라우드 LLM으로 나가는 사용자 작성 자유 텍스트에서 민감 정보를 자리표시자로 가리는 PR입니다. 커밋은
ADR-019와 설계 456, 핸드오프(orchestrator), Codex 구현으로 구성됩니다.

**Part A — 결정(ADR-019, ADR-009 보완).** ADR-009의 화이트리스트는 "어떤 필드가 나가는지"를
통제하지만 "필드 안에 무엇이 들었는지"는 통제하지 못합니다. ADR-019는 사용자가 쓴 자유 텍스트에
한해 내용을 가리는 보완 계층을 두고, 이를 각 호출부가 아니라 게이트웨이에서 강제합니다. 공개 데이터는
선언 대상이 아니라 가리지 않습니다.

**Part B — 구현(#456, 설계 456).** `mask_sensitive_text`는 개인식별 정보 다섯 종을 먼저 가리고(주민번호
→ 카드 → 전화 → 이메일 → 계좌 순), 이어서 문장 단위로 개인 맥락 표지가 있을 때만 수량·금액을
가립니다. 소수점은 문장 경계로 보지 않습니다. `CloudSafePayload.free_text_fields`로 대상 필드를 선언하고,
`PrivacyGate.mask`가 선언된 필드만 `model_copy`로 바꿉니다. `LLMGateway`는 직접 클라우드 호출과 클라우드
검증 두 경로 모두에서 `guard` 다음 `mask`를 적용하고, client 메시지와 캐시 키에는 마스킹된 payload만
씁니다. `LLMCompletionResult.masked_categories`가 서비스를 거쳐 두 API 응답과 Obsidian 노트 frontmatter로
전달됩니다. 로컬 경로(로컬 LLM, 로컬 임베딩, Obsidian 본문)는 원문을 유지합니다.

이번 리뷰는 우회 경로가 없는지, 공개 사실을 해치지 않는지, 실제 전송 메시지에 원문이 남지 않는지를
축으로 봤습니다.

## Suggestions

**S1. 제3자 보유나 매수 권유 문장에서 공개 수치가 가려집니다 — 중간, 사례가 쌓이면 규칙 보정.** 실제
문장 확인에서 "엔비디아 시총 4조 달러인데 지금 매수해도 될까?"의 금액과 "버크셔가 애플 3억 주를
보유하고 있다는데 영향은?"의 수량이 가려졌습니다. "매수"와 "보유"가 개인 맥락 표지로 잡혔기 때문입니다.
더 많이 가리는 안전한 방향의 오류이고 자리표시자가 남아 LLM이 의도를 이해하므로 지금은 허용합니다.
보정 방향은 "매수·보유"를 1인칭 표지(내, 제가, I)와 함께 나올 때만 개인 맥락으로 보는 것입니다. 다만
"300주 보유 중인데"처럼 주어가 생략된 한국어 문장을 놓칠 수 있어, 실제 질문 사례를 모은 뒤 결정하는
편이 낫습니다.

**S2. 새 자유 텍스트 필드의 선언 누락은 막지 못합니다 — 중간, 리뷰 체크 항목 필요.** ADR-019 Consequences에
적은 대로, 새 `CloudSafePayload`에 사용자 작성 텍스트 필드를 추가하면서 `free_text_fields`를 선언하지 않으면
마스킹되지 않습니다. `docs/harness/local-review-policy.md`(protected)에 "클라우드 payload에 사용자 작성
텍스트가 추가되면 `free_text_fields` 선언 확인" 항목을 넣는 것을 제안합니다. protected 문서라 이 PR에는
넣지 않았고, 개발자 승인 후 별도로 반영하겠습니다.

**S3. 10~16자리 하이픈 없는 숫자는 맥락 없이 계좌번호로 가립니다 — 경미, 허용.** 시가총액을 원 단위
숫자로 적는 경우처럼 드문 공개 수치도 가려질 수 있습니다. 실제 질문에서 거의 쓰이지 않는 표기라 허용합니다.

## Questions

**Q1. 실제 LLM 호출에서 원문이 전송되지 않는가 — 리뷰 중 확인해 해소했습니다.** 실제 로컬 DB(2,703건
임베딩), Ollama, LLM 프록시로 Q&A를 호출하면서 `OpenAIClient.complete_json`에 전달된 메시지를 가로챘습니다.
질문 "제 계좌에 삼성전자 300주를 평단 7만 원에 샀는데 최근 주가 하락 리스크는? 연락처 010-1234-5678"은
"제 계좌에 삼성전자 [수량]를 평단 [금액]에 샀는데 최근 주가 하락 리스크는? 연락처 [전화번호]"로
전송됐고, 원문 `300주`·`7만 원`·`010-1234-5678`은 메시지 어디에도 없었습니다. 응답 `masked_categories`는
`[PHONE, QUANTITY, AMOUNT]`였고 답변은 정상 생성됐습니다.

**Q2. ADR-019 승인 — 개발자 판단이 필요합니다.** 개인정보 경계를 바꾸는 결정이라 ADR-019는 Proposed로
두었습니다. 이 PR 머지를 승인으로 보고 Accepted로 바꿀지, 별도로 확정할지 정해 주세요.
