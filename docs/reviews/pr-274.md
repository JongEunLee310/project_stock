## Review Summary

이슈 #269의 구현입니다. `GET /assets/{asset_id}/catalysts?limit=10`을
신설해 자산별 예정 이벤트 타임라인을 반환합니다. 변경은 5개 파일 +257줄로,
신규 도메인 `app/domains/catalysts/`(schema·service)와 라우트 1개,
테스트 파일 1개입니다.

- 구조가 #267 research-summary 선례를 그대로 따릅니다:
  `AssetRepository.get_by_id` 존재 검증(미존재 404 `ASSET_NOT_FOUND`),
  `asset.id % N` 템플릿 로테이션, 점검 유도형 한국어 콘텐츠.
- 이벤트는 오늘(UTC) 기준 상대 일자로 생성되어 `event_date` 오름차순
  정렬·limit 적용 후 반환됩니다. `event_type`은 설계 enum 10값을 정확히
  사용하고, `is_estimated`로 확정/예상을 구분합니다.
- `limit`은 `Query(ge=1, le=100)`로 검증됩니다. 신규 테이블·마이그레이션이
  없어 배포 부담이 없습니다.
