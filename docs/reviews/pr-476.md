# PR #476 로컬 리뷰 — feat: EDGAR 10-K 사업·위험요인 섹션 수집 (#472)

## Review Summary

미국 관심종목의 최근 10-K 2건에서 사업·위험요인 섹션을 수집해 지식 정본에 저장하는 PR입니다. 커밋은
핸드오프, 핸드오프 보강(job timeout), Codex 구현으로 구성됩니다.

**Part A — EDGAR 수집(설계 445 §3·§5).** `EdgarFilingProvider`는 티커와 CIK 매핑을 인스턴스 안에서 한 번
읽고, 제출 목록에서 10-K만 최신 순으로 고릅니다. 모든 요청에 `User-Agent`를 붙이고 0.2초 간격을 둡니다.
`extract_10k_sections`는 블록 경계를 줄바꿈으로 남긴 뒤 줄 시작 제목만 인정하고, 같은 제목 중 가장 긴
구간을 고릅니다. `FilingCollectionService`는 두 섹션이 모두 저장된 보고서는 본문을 받지 않고, 종목 단위로
commit하며, 국내 종목은 `unsupported`로 넘깁니다.

**Part B — job timeout(핸드오프 Addendum).** 실측에서 공시 537청크 임베딩에 17분 18초가 걸렸습니다. RQ
2.9.1 기본 timeout은 180초라서, 이대로면 매시 임베딩 job이 강제 종료되고 롤백돼 공시 청크가 적재되지
않습니다. `ScheduleDefinition.job_timeout`을 두고 임베딩 1800초, 일일 리서치 3600초, 공시 수집 900초를 cron
등록·수동 실행·직접 enqueue에 넘깁니다. 실 DB에서 `embed_documents` 최장 실행이 이미 2분 39초여서, 공시가
없어도 곧 닿을 한계였습니다.

이번 리뷰는 실제 10-K에서의 추출 정확도, 외부 API 예의(User-Agent·간격), 중복 수집 방지, 실제 워커에서
끝까지 도는지를 축으로 봤습니다.

## Suggestions

**S1. `FILING_PROVIDER` 기본값이 mock이라, 설정 없이 배포하면 주간 job이 mock 공시를 저장합니다 — 중간,
운영 설정으로 해소.** 다른 수집 job(뉴스·가격)과 같은 정책이지만, 로컬 `.env`에는 `NEWS_PROVIDER=rss`처럼
실제 provider가 지정돼 있고 `FILING_PROVIDER`는 아직 없습니다. 머지 전에 `.env`에 `FILING_PROVIDER=real`과
`SEC_USER_AGENT="<이름> <이메일>"`을 추가해 주세요. 설정하지 않으면 토요일 01:00 UTC에 mock 공시가
저장되고 임베딩까지 됩니다.

**S2. 실 DB에 `running` 상태로 남은 job 기록이 있습니다 — 기존 문제, 후속 이슈 권장.** `news_collection`
41건, `decision_review_trigger_evaluation` 7건, `llm_analysis` 1건이 `running`으로 남아 있습니다. 워커가
재시작되거나(로그에 Redis 연결 timeout으로 종료한 기록이 있음) job이 강제 종료되면 `JobRunService.fail`이
호출되지 않기 때문으로 보입니다. 이번 PR과 무관하지만, timeout으로 끊긴 실행을 실패로 정리하는 방법을
별도 이슈로 다루는 것이 좋겠습니다.

**S3. 머리말·꼬리말이 본문에 섞입니다 — 경미, 설계상 허용.** `Table of Contents`, `Apple Inc. | 2025 Form
10-K | 4` 같은 쪽 표시가 섹션 본문과 청크에 들어갑니다. 검색 실측에서 결과 품질에는 영향이 없었습니다.

길이는 핸드오프 전 실측과 같습니다(예: NVDA FY2026 Item 1 4.8만 자, Item 1A 11.5만 자). 재실행하면 12건
모두 건너뛰고, 국내 종목은 `unsupported`로 기록됐습니다.

**Q2. 저장한 공시가 검색에 쓸 만한가 — 리뷰 중 확인해 해소했습니다.** 실제 Ollama로 537청크를 적재한 뒤
`KNOWLEDGE` 필터로 검색했습니다. NVDA "export controls China data center" 질의에는 미국 수출 통제 위험요인이,
AAPL "supply chain concentration Asia manufacturing" 질의에는 아시아 외주 생산 집중 위험요인이 상위에
나왔습니다. 기존 Q&A와 일일 리서치는 아직 `NEWS`만 검색합니다(#474).
