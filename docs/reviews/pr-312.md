## Review Summary

asset detail 계약에 목표 주가 컨센서스(`target_price_high`·`target_price_low`·
`target_analyst_count`)를 additive로 추가하고, yfinance `Ticker.info` 기반
실수집과 1시간 TTL 캐시를 도입한 PR입니다. 설계 문서의 결정 사항(quote 경로와
분리된 provider 메서드, mock 불변식, null 허용)과 구현이 일치합니다.

- `PriceTargetResult`와 `MarketDataProvider.get_price_targets`가 분리 메서드로
  추가되어 quote 경로(TTL 60초)의 성능에 영향을 주지 않습니다. 기본 구현이
  전부 null인 결과를 반환하므로 다른 provider 구현체의 회귀가 없습니다.
- 캐시 직렬화는 기존 typed marker 방식(Decimal 보존)을 재사용해 roundtrip
  후에도 Decimal 산술이 안전함을 확인했습니다.
- 서비스는 컨센서스 평균을 우선 사용하고 없으면 기존 `quote.target_price`로
  fallback하며, `target_upside_percent`를 최종 평균 기준으로 파생합니다.
  zero-price 가드(`0.00` 반환)가 있습니다.
- mock은 AAPL에 대해 high(250) ≥ mean(220) ≥ low(180) 불변식을 지키고,
  그 외 심볼은 전부 null로 미제공 경로를 exercise합니다.
- `_optional_int`는 bool·음수·NaN을 배제합니다.
