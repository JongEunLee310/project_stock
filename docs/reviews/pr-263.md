## Review Summary

PR #261 리뷰 S1 후속입니다. 포트폴리오 집중도 시그널의 `key_points` 불릿에
원시 Decimal이 노출되던 문제를 설계 문서
(`docs/designs/262-concentration-bullet-format.md`)의 계약대로 고쳤습니다.

- **포맷 헬퍼** — `_format_percent`는 `f"{value:.1%}"`로 백분율 소수 1자리를,
  `_format_amount`는 `f"{value.normalize():f}"`로 후행 0 제거·지수 표기 없는
  문자열을 만듭니다. 설계가 경고한 `normalize()` 단독 사용의 지수 표기
  문제(`1E+3`)를 `:f` 포맷으로 회피했고, 경계 테스트가 이를 고정합니다.
- **불릿 조립** — 수치를 문장 뒤 괄호로 배치해("현재 비중이 임계치를
  초과했습니다 (65.2% > 60.0%)") 조사 불일치도 함께 해소했습니다. 변경은
  `check_concentration`의 불릿 2개뿐이고 reason·evidence·응답 계약과 다른
  생성 경로 2곳은 손대지 않았습니다.
- **테스트** — 픽스처의 `cash_balance`를 조정해 비중이 설계 예시 값
  (65.217…% → "65.2%")에 정확히 걸리게 만들고 불릿 전체 문자열을 리터럴로
  단언합니다. 비중 변경에 따라 파생되는 `score` 기대값(78 → 65)도
  `_score_from_weight` 로직과 일치하게 갱신됐습니다. evidence의 원값 보존
  단언은 그대로 유지됩니다.

protected 파일(`app/domains/signals/types.py`)은 변경이 없습니다.
