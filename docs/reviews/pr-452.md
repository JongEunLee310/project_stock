# PR #452 로컬 리뷰 — feat: RAG 1차 뉴스 청킹·임베딩 job과 RSS 본문 정제 (#441)

## Review Summary

뉴스 원문을 정제·청킹·임베딩해 벡터 저장소에 적재하는 인덱서와 `embed_documents` job, backfill
스크립트를 추가하는 PR입니다. 커밋은 핸드오프 두 건, Codex 구현 두 건(인덱서·job, RSS 본문 정제
보정)으로 구성됩니다.

**Part A — 인덱서와 job(#441, 설계 438 §3·§6).** `app/domains/rag/indexing.py`의 순수 함수
(`compose_embedding_text`, `chunk_text`, `embedding_input_hash`)가 임베딩 입력을 만듭니다.
`EmbeddingIndexer.run`은 `RawNewsEventRepository.list_after_id`로 원문을 페이지 단위로 훑고,
`VectorStore.get_content_hashes`와 비교해 바뀐 원문만 `max_documents`개까지 모읍니다. 그다음 한 번의
`embed` 호출로 임베딩하고, 결과 개수와 차원을 확인한 뒤에야 원문 단위로 `delete_by_source`와
`upsert`를 하고 한 번 커밋합니다. 종목 매핑은 `NewsItemRepository.list_by_raw_event_ids`로 가져와
`asset_ids`에 넣습니다. rag 코드는 다른 도메인 테이블을 직접 쿼리하지 않습니다(ADR-018 R2).
`embed_documents_job`은 `JobRunService`로 실행을 기록하고, `EmbeddingError`이면 실패만 기록하고
오류를 다시 던지지 않습니다. 스케줄은 수집 job 뒤인 `"20 * * * *"`입니다. 반환값이 생겨
`SchedulerJobFunc`가 `Callable[..., object]`로 넓어졌습니다.

**Part B — RSS 본문 정제(#441 보정, 실데이터 근거).** 검증 중 `raw_news_events.body`가 Google News
RSS의 HTML 조각임을 확인했습니다. `clean_body_text`가 `lxml`로 텍스트만 꺼내고 `<li>`를 줄로
나누며, 파싱이 실패하면 정규식으로 대체합니다. `compose_embedding_text`는 제목만 반복하는 본문을
비어 있는 것으로 보고, quality를 정제 본문 길이로 판정합니다.

이번 리뷰는 실패 시 무변경 보장, 멱등성, 경계 규칙, 그리고 실데이터에서의 정제 결과를 축으로
봤습니다.

## Suggestions

**S1. 임베딩 실패 메시지가 공급자를 OpenAI로 단정합니다 — 경미, 후속 정리 권장.**
`app/adapters/embedding/openai.py:45`의 `"OpenAI embedding request failed"`가 그대로
`job_runs.error_message`에 남습니다. 실제 공급자는 로컬 Ollama라 운영 기록을 읽는 사람이 혼동할 수
있습니다. `"embedding request failed (model=..., base_url=...)"`처럼 모델과 엔드포인트를 담으면
원인 파악이 빨라집니다. #442에서 같은 예외를 API 응답(503)으로 바꿀 때 함께 정리하면 됩니다.

**S2. 매 실행마다 원문 전체를 훑습니다 — 경미, 현재 규모에서 허용.** 변경 감지를 위해 매시
2,703건을 모두 읽고 해시를 계산합니다. 실측으로 재실행 한 번이 수 초 안에 끝났고, 핸드오프에서도
현재 규모의 가정으로 명시했습니다. 원문이 수만 건 단위로 늘면 워터마크(마지막 처리 id와
`updated_at`) 방식으로 바꾸면 됩니다.

**S3. 형태 2(다중 헤드라인) 단위 테스트 픽스처는 재구성본입니다 — 경미, 실데이터로 보완 완료.**
핸드오프에 원문을 잘라 넣어 Codex가 재구성 픽스처를 썼습니다. 대신 orchestrator가 실데이터 2,703건
전체에 정제 함수를 돌려 URL·`href`·엔티티 잔존 0건과 `id=88`의 줄 단위 정제를 확인했습니다. 원문
그대로의 픽스처로 바꾸는 것은 다음에 이 함수를 고칠 때 하면 충분합니다.
