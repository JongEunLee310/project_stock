# RAG 1차 검색 품질 기준선 — 2026-10-12

이슈 #444, 에픽 #438. 평가 세트 `docs/experiments/rag-eval-set.json`(18문항)으로 RAG 1차의 검색과
답변 품질을 측정한 기준선이다. 이 결과로 검색 하한과 `TITLE_ONLY` 가중치를 조정했고(설계 438 §5.2),
ADR-018 V2(하이브리드 검색)와 #445 코멘트의 B·C 재검토 판단에 쓴다.

## 측정 환경

| 항목 | 값 |
|---|---|
| 데이터 | 로컬 DB 볼륨 복제본(2026-07-23 스냅샷), `raw_news_events` 2,703건 전량 임베딩 |
| 코퍼스 성격 | Google News RSS 헤드라인. 정제 후 `TITLE_ONLY` 2,652건, `SUMMARY` 44건, `FULL` 7건 |
| 임베딩 | 로컬 Ollama `ollama/ollama:0.40.3`, `bge-m3`(1024차원), CPU |
| 저장소 | `pgvector/pgvector:pg16`, HNSW cosine |
| LLM | `LLMGateway` cloud, 로컬 openai-oauth 프록시 경유 |
| 기준 시각 | `reference_now = 2026-07-24`, `lookback_days = 365` |
| 실행 | `scripts/evaluate_rag_retrieval.py --with-llm` |

## 평가 세트

질문 18개다. 긍정 질문 14개는 4개 종목(NVDA, GOOGL, AAPL, 005930)의 실제 주제를 다루고, 부정 질문
4개는 해당 종목에 관련 기사가 없는 주제(CEO 교체, 비전프로, 구글 전기차, 삼성 자사주 소각)다. 관련
근거는 해당 종목에 연결된 원문 가운데 제목이 질문별 정규식에 맞는 기사로 정의했다. 사람이 문서마다
판단한 라벨이 아니므로, 정규식에 걸리지 않는 관련 기사는 비관련으로 집계된다. 이 때문에 precision은
실제보다 낮게 나올 수 있다.

## 결과

### 검색 설정 비교

| 설정 | 긍정 hit@8 | 긍정 precision@8 | 긍정 top1 | 부정 근거 0건 비율 |
|---|---|---|---|---|
| 하한 0.30, 가중치 0.8(조정 전) | 0.786 | 0.554 | 0.714 | 0.000 |
| 하한 0.30, 가중치 1.0 | 0.857 | 0.571 | 0.786 | 0.000 |
| **하한 0.50, 가중치 1.0(채택)** | **0.857** | **0.593** | **0.786** | **0.000** |
| 하한 0.55, 가중치 1.0 | 0.786 | 0.667 | — | 0.500 |
| 하한 0.60, 가중치 1.0 | 0.500 | 0.792 | — | 0.500 |

- **가중치 0.8은 역효과였다.** 코퍼스의 98%가 `TITLE_ONLY`라서, 이 가중치는 사실상 `SUMMARY` 44건만
  끌어올려 관련 헤드라인을 밀어냈다. 1.0으로 바꾸자 hit@8과 top1이 함께 올랐다.
- **하한만으로는 부정 질문을 거를 수 없다.** 관련 후보와 비관련 후보의 원점수 중앙값이 0.573과 0.526으로
  겹치고, 부정 질문의 최고 점수도 0.51~0.63이다. 0.55 이상으로 올리면 부정 질문 절반을 거르지만
  긍정 hit가 떨어진다. 그래서 0.50(긍정 지표 손실 없이 정밀도만 오르는 최대값)을 채택하고, 부정 질문은
  LLM 판정에 맡겼다.

| 부정 질문 `insufficient_evidence` 비율 | 1.000(4/4) |
| 긍정 질문 `insufficient_evidence` 비율 | 0.286(4/14) |

첫 질문의 106초는 Ollama가 유휴 시간 뒤 모델을 다시 올리는 콜드 스타트로 본다. 운영에서 첫 요청이
느릴 수 있으므로 FE 타임아웃은 넉넉히(60초 이상) 잡는다.

검색 실패 3건은 모두 한국어 질문과 영어 헤드라인 사이의 교차언어 검색에서 나왔고, 특히 고유명사
음차에 약하다. 헤드라인 한계 1건은 근거 자체에 답이 없는 경우라 LLM이 올바르게 부족 판정을 내렸다.

## 결론과 후속

1. **채택 설정**: `MIN_SCORE = 0.5`, `TITLE_ONLY_WEIGHT = 1.0`(설계 438 §5.2 반영, #444 PR).
2. **근거 없는 답변 방지는 작동한다.** 부정 질문 4/4가 부족 판정을 받았고, 수치를 지어낸 사례는 없었다.
3. **교차언어 고유명사가 가장 큰 약점이다.** 후보 개선책은 다음과 같다. 효과는 이 평가 세트로 다시
   측정한다.
   - 질문에 종목 영문명과 티커를 덧붙여 임베딩(구현이 가장 간단)
   - 질문 재작성(LLM으로 영문 검색어 생성, ADR-018 T1과 비용 고려)
   - 하이브리드 검색(키워드 + 벡터, ADR-018 V2)
4. **헤드라인 한계는 예상대로다.** 이번 세트에서 직접 드러난 것은 1건이지만, 답변된 질문도 대부분
   "제목 수준이라 세부 내용은 확인할 수 없다"는 한계를 밝혔다. #445(공시 수집) 이후 같은 세트로 다시
   측정해 비교하고, 그 결과로 B(기사 원문 수집)·C(본문 제공 소스) 재검토 여부를 정한다.
5. **평가 세트 확장**: 2차 공시 근거가 들어오면 `FILING_SECTION`을 정답으로 하는 질문(사업 구조,
   위험요인)을 추가한다.
